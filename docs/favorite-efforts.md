# 收藏模型与思考强度

模型菜单的收藏保存的是“模型 + 思考强度”的组合，同一个模型可以收藏多个强度。为了不让收藏夹堆满重复的模型，菜单按模型合并显示，并自动记住每个模型上次用的强度。所有入口（设置页三项、聊天栏主模型与子代理、子代理确认徽章）共用同一份数据。

代码位置：数据与规则在 `src/client/model-preferences.ts`，界面在 `src/client/ModelPicker.tsx`。回到 [README](../README.zh.md)。

## 交互规则

- **收藏分组**：一个模型只占一行，收藏过的强度显示为行内标签，样式与底部“思考强度”按钮一致。标签按模型自己的强度顺序排列，“默认”（提供方默认）在最前，位置固定；不支持思考强度的模型不显示标签。
- **最近使用**：最近点过“应用”的 6 个模型，每个模型一行，标签是上次用的强度；与收藏完全相同的组合不再重复出现，所以可能少于 6 行。
- **点模型名**：草稿强度依次取：当前入口正在用这个模型时沿用当前强度 → 上次给这个模型点“应用”时的强度 → 提供方默认。收藏、最近使用、提供方分组、搜索结果都一样。
- **点强度标签**：直接把这个组合放进草稿，不推断。
- **收藏**：星标在底部编辑区，紧跟“模型 · 强度”文字，收藏的就是这行字；切换强度时文字和星标一起变。提供方分组的模型行没有星标。
- **取消收藏**：鼠标移到收藏分组的强度标签上，标签右上角浮出一个 ★ 角标（同 macOS 通知的关闭角标），点它即取消这一个强度；不支持思考强度的模型，★ 出现在该行末尾。键盘聚焦标签后按 Delete 或 Backspace 效果相同；触屏设备上角标常显。编辑区的星标同样可以取消当前组合。
- **原位撤销**：取消后标签不会立刻消失，而是变成虚线空心、角标变 ☆，列表不跳动；再点 ☆ 即恢复。关闭菜单后才真正从收藏分组移除。失效强度也用同样方式清理。
- **保存时机**：收藏点了就保存，不受“应用 / 取消”影响；模型路由仍只在“应用”后改变。
- **失效强度**：目录里不再提供的强度，标签变灰加删除线；点它时改用该模型的默认强度，编辑区说明原因。模型整个不在目录里时，收藏暂时隐藏、数据保留。
- **上限**：收藏最多 40 个组合，满了以后没收藏过的组合星标不可点；上次强度最多记 100 个模型。

## 动效与无障碍

- 标签和星标按下即缩小到 0.96，选中状态立即切换，不做颜色渐变。
- 收藏时星标从 0.85 平滑回到原尺寸（250ms、无回弹），列表不自动滚动；读屏播报“已收藏 / 已取消收藏 + 组合名”。
- 角标在悬停或聚焦时 120ms 淡入并从 0.85 放大到原尺寸。
- 系统开启“减少动态效果”时去掉所有缩放，角标只淡入。
- 键盘：上下键在行之间移动，左右键在同一行的模型名与标签之间移动，Tab 可到星标。

## 存储与迁移

- 数据在浏览器 localStorage 的 `dsh-model-switch/picker-v2`，不同步设备。
- `favorites` 存 `[provider, model, effort]`，`effort` 为 `null` 表示提供方默认；`history` 最新在前，每个模型一条，同时提供“最近使用”和“上次强度”。
- 首次读取时若没有 v2，从 `dsh-model-switch/picker-v1` 迁移：旧收藏变成该模型的“默认”标签，旧最近使用保留但不带强度。v1 只读不写，退回旧版插件时原有收藏仍在。

## 预览与验证

- 可交互预览：`npm run preview`，打开 <http://127.0.0.1:5179/>。页面用正式 `ModelPicker` 和假目录，提供空白、旧版迁移、组合收藏、失效强度、收藏已满五个场景；数据属于预览页面自己的 origin，不影响 DSH。预览源码在 `preview/`，`@deepseek-ai/dsh-client-ui-primitives` 在预览里替换为只含两个图标的替身。
- 单元测试：`tests/model-preferences.spec.ts` 覆盖组合收藏、上限、v1 迁移、起始强度顺序、收藏与最近使用的行合并。
